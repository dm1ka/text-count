# TextCheck

A really simple text checker built with HTML, CSS and JavaScript.

## Features

- Counts letters and numbers.
- Counts words.
- Lets you set a word goal.
- Clears the text with one button.
- Shows how many words are left to reach your goal.
- Displays a progress bar for your word goal.

## How to run

- Download and extract the project files.
- Open `index.html` in your browser.
- Start typing or paste your text!
